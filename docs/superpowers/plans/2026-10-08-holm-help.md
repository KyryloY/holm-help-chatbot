# Holm Help Implementation Plan

> **For agentic workers:** Execute inline in this session.

**Goal:** Build the Holm Help portfolio demo (LangGraph + Chainlit) as a standalone public repo.

**Architecture:** Explicit StateGraph in `src/holm_help`, Chainlit entry `app.py`, SQLite checkpointer + journal, fake model for tests.

**Tech Stack:** Python 3.12, LangGraph 1.x, Chainlit 2.x, langgraph-checkpoint-sqlite, langchain google-genai, pytest

## Global Constraints

- English everywhere in the repository
- No langchain-classic / ConversationChain / CrewAI / create_react_agent
- No Literal AI / cloud data layer / RAG / vector DB
- PowerShell 5.1: separate-line commands, no `&&`
- Windows-friendly paths

### Task 1: Scaffold

- Create pyproject.toml, .gitignore, .env.example, data fixtures, package layout
- Create venv with Python 3.12 and install deps

### Task 2: Core library

- config, state, tools, journal, guard/card masking, decide logic, graph, fake model

### Task 3: Chainlit app

- app.py with Steps, interrupt resume, action callbacks

### Task 4: Docs + tests

- README, chainlit.md, docs/scenarios.md, pytest suite

### Task 5: Verify + publish

- Run tests, smoke Chainlit, screenshots, GitHub repo
