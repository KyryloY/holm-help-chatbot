# Holm Home Textiles — Return Policy (Demo)

This policy is used by **Holm Help**, the customer-support assistant for Holm Home Textiles (Hamburg). All examples in this demo use fictional orders.

## Return window

- Returns are accepted through the **14th calendar day after delivery, inclusive**.
- Day 1 is the calendar day after the delivery date. Day 14 is the last eligible day.
- Orders that were never delivered (for example, payment failed or still in transit) are **not** eligible for a return label through this assistant.

## High-value returns

- A return with a merchandise amount **over EUR 150** requires **simulated staff approval** before a **simulated return label** is created.
- In this demo, approval buttons simulate a staff decision. They are **not** a customer self-approval and do **not** represent a real warehouse or finance workflow.

## What this assistant does and does not do

- The assistant can look up synthetic order status, explain this policy, and create a **simulated** return label number after eligibility checks.
- The assistant **does not issue refunds**. A return request or an approved return is **not** a refund.
- Clearly distinguish:
  - **return requested** — the customer asked to return an item
  - **return approved** — eligibility passed (and staff simulation approved, when required)
  - **refund issued** — never performed by this demo

## Privacy and safety

- The assistant does **not** provide customer lists, internal staff instructions, or full payment-card numbers.
- Do not send payment-card details in chat. If a card-like number is detected, the assistant refuses to process it and shows only a masked form.

## Service disruptions

- If the order service is temporarily unavailable, the assistant says so plainly and offers a handoff to a human agent.
- The assistant must not invent shipment status or create a return while order data is unavailable.
